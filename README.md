# Lapo Odunjo — Portfolio

Personal site for [Lapo Odunjo](https://lapoodunjo.com) (Onaolapo Michael Odunjo) — AI product work, project case studies, experience, and essays.

**Live:** [lapoodunjo.com](https://lapoodunjo.com)

## What's here

- Project case studies with problem statements, architecture, and outcomes
- Featured work: Kova, GTM Intelligence Platform, Regulatory Compliance Cockpit, Transcript Intelligence
- Writing and contact

Several production repositories are private; the portfolio documents architecture and results without exposing client IP.

## Stack

Next.js 16 · TypeScript · React 19 · Tailwind CSS 4 · Vercel

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command        | Description              |
|----------------|--------------------------|
| `npm run dev`  | Start dev server         |
| `npm run build`| Production build         |
| `npm run start`| Serve production build   |
| `npm run lint` | Run ESLint               |

## Structure

- `app/` — routes (home, projects, experience, writing, how-i-build)
- `components/` — UI (CloudScene hero, nav, project detail, game layer)
- `lib/` — project and essay data, site constants

## Deploy

Optimized for [Vercel](https://vercel.com). `lapoodunjo.com` is the default canonical URL; override with `NEXT_PUBLIC_SITE_URL` if needed.
